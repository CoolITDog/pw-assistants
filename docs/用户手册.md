# Excel Processor 用户手册

## 简介

Excel Processor 是一款 Windows 桌面应用程序，用于读取 Excel / CSV 表格数据，对数据进行回水线计算与处理，并将结果导出为新的 Excel 文件。程序打包为独立 `.exe`，无需安装 Node.js 或其他运行环境，双击即可使用。

支持的输入格式：`.xlsx`、`.xls`、`.csv`

---

## 安装与启动

### 方式一：安装包

双击 `Excel Processor Setup 1.0.0.exe`，按照安装向导完成安装。安装完成后，在桌面或开始菜单中找到 **Excel Processor** 图标，双击启动。

### 方式二：免安装

进入 `release/win-unpacked/` 目录，直接双击 `Excel Processor.exe` 即可运行。

## 操作流程

### 第一步：导入文件

1. 点击 **📂 导入文件** 按钮
2. 在弹出的文件选择对话框中，选择一个 `.xlsx`、`.xls` 或 `.csv` 文件
3. 文件导入成功后：
   - 文件名显示在按钮右侧
   - 如果文件包含多个 Sheet，会出现下拉框供选择
   - 下方表格自动预览前 20 行源数据

#### 切换 Sheet

如果文件包含多个 Sheet，点击 Sheet 下拉框选择目标 Sheet，数据会自动刷新。

#### 错误处理

- 如果文件格式不支持或文件损坏，界面会显示红色错误提示
- 请确保文件未被其他程序锁定（如 Excel 正在打开该文件）

---

### 第二步：计算回水线

导入数据后，进入"配置规则"区域进行回水线计算。

#### 数据格式要求

源数据表头需要遵循以下命名规范：

| 列名格式 | 说明 | 示例 |
|----------|------|------|
| `距坝里程` | 各断面到坝的距离（数值） | 0.5, 1.0, 2.5 |
| `断面号` | 断面编号 | 断面1, 断面2 |
| `多年平均水面线` | 多年平均水位数据 | 105.2 |
| `{频率}_天然水面线` | 某频率下的天然水面线 | `0.05_天然水面线`、`0.1_天然水面线` |
| `{频率}_{水位}` | 某频率下某回水位的水面线 | `0.05_145`、`0.1_140` |

其中 `{频率}` 为洪水频率（如 `0.05`、`0.1`），`{水位}` 为回水位数值（如 `145`、`140`）。

#### 执行计算

1. 点击 **📥 计算** 按钮
2. 程序自动完成以下处理：
   - 识别所有回水线（根据表头中的 `_` 分隔符自动分组）
   - 计算天然水面线与回水线的差值
   - 查找 0.3m 差值区间，通过线性插值计算**回水末端**断面（距坝里程、天然水位、回水位）
   - 将回水末端断面插入原表对应位置
   - 计算**回水终点**（回水位与多年平均水面线的交点）
   - 生成**淹没线**列（取回水线与基准值的较大值，延伸至处理终点）
3. 计算完成后，结果按回水线分组为多个子表

#### 预览结果

- 使用"预览子表"下拉框切换不同回水线的计算结果
- 每个子表显示该回水线对应的所有数据，包括插入的末端断面和终点行
- 表格底部显示总行数和列数

---

### 第三步：导出结果

1. 确认计算结果无误后，点击 **📥 生成表格** 按钮
2. 在弹出的保存对话框中，选择保存路径并输入文件名（默认为 `output.xlsx`）
3. 导出完成后：
   - 显示绿色成功提示，包含文件保存路径
   - 点击 **打开目录** 按钮可直接打开文件所在文件夹
4. 导出的 `.xlsx` 文件中，每个回水线对应一个独立的 Sheet（如 `回水线_145`、`回水线_140`）

#### 导出失败

- 如果计算后无数据，会提示"当前规则过滤后无数据"
- 如果保存路径无写入权限或磁盘空间不足，会显示具体错误信息
- 请确保目标路径未被其他程序占用

## 计算原理说明

### 回水末端计算

在天然水面线与回水线差值经过 0.3m 的位置，通过线性插值求解：

- 已知前后两个断面的距坝里程 (S1, S2)、天然水位 (a, A)、回水位 (b, B)
- 计算斜率后插值得到差值恰好为 0.3m 的精确位置和对应水位

### 回水终点计算

回水末端的回水位与多年平均水面线的交点：

- 在多年平均水面线上找到回水位所在的区间
- 通过线性插值计算精确的距坝里程

### 淹没线生成

- 从坝址到回水末端：取回水线值与基准值（回水位 + 偏移量）中的较小值
- 从回水末端到处理终点：取回水末端的回水位值
- 偏移量：频率 0.05 时为 1，其他频率为 0.5

## 常见问题

**Q: 导入文件后表头显示异常（如出现"列1"、"列2"等默认名称）？**
A: 程序会自动检测表头行数。如果第一列第一行就是数值，程序可能误判表头。请确保表头行的第一列不是纯数字。

**Q: 计算按钮点击后没有结果？**
A: 请检查源数据表头是否符合命名规范（包含 `_天然水面线`、`_` + 回水位等格式）。程序通过表头中的 `_` 分隔符来识别回水线分组。

**Q: 导出的 Excel 文件中某些单元格为空？**
A: 这是正常现象。插入的末端断面和终点行只包含关键计算字段（距坝里程、断面号、水位值），其他列为空。

**Q: 数值精度问题？**
A: 程序内部使用高精度计算库（Decimal.js），距坝里程保留 2 位小数，水位值保留 3 位小数，读入数据保留 6 位小数。

## 待补充功能

以下功能尚在规划中，后续版本将陆续支持：

### 1. 导入列名兼容处理

当前版本要求源数据表头严格遵循命名规范（如 `{频率}_天然水面线`、`{频率}_{水位}`）。实际使用中，用户提供的 Excel 文件列名可能存在以下不规范情况：

- 列名中包含多余空格或特殊字符
- 列名大小写不一致
- 列名使用了不同的分隔符（如 `-`、`.` 代替 `_`）
- 列名缺少必要的前缀或后缀
- 多级表头合并后产生的非预期列名

后续计划：增加列名映射/别名配置功能，允许用户在导入后手动或自动将不规范列名映射为程序可识别的标准列名，降低对源数据格式的依赖。

### 2. 导出表格格式调整

当前版本导出的 `.xlsx` 文件为简单的单行表头 + 数据行结构。后续需要支持按照目标格式进行调整，包括但不限于：

- 多级表头（合并单元格）：将 `{频率}_天然水面线` 等列名还原为多行表头结构，频率作为上级表头，天然水面线/回水位/淹没线作为下级表头
- 单元格样式：表头背景色、边框、字体加粗等
- 列宽自适应：根据内容自动调整列宽
- 数值格式：指定小数位数、百分比等显示格式
- 冻结窗格：冻结表头行和关键列，方便滚动查看
